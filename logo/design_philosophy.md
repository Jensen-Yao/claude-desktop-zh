# 朱印 (Cinnabar Seal)

A design philosophy for the Claude Desktop Chinese language pack identity.

## 哲学

温润的宣纸米色为底,如同一页摊开的信笺。墨色方印居于中央,方正而不失圆润
—— 方,是汉字的结构骨架;圆,是现代应用的圆角语言。两者相切,即是"翻译"
本身的形状:一种语言安放进另一种语言的容器。

朱砂红是唯一的强调色。它来自印章,来自批注,来自语文老师在作文本上落下
的那一笔。在整片墨色与米色构成的静默里,一点朱砂足以让所有视线驻足。

图案语汇克制到近乎吝啬:细若蚊足的方格暗纹铺陈底层,如同稿纸的边界线;
中宫收放的几何笔画构成主标;一枚小印落于角落,如同签名。没有多余的光影、
渐变或装饰 —— 每一根线条的位置都经过反复推敲,仿佛匠人伏案数日、
以圆规与界尺逐一校正后的成果。

留白即呼吸。字与印之间、格与格之间,大面积的米色承接所有张力。
构图的平衡不是对称,而是配重:主印居中偏上,小印坠于右下,
视线由此完成一次从"注视"到"落款"的旅行。

最终成物应当像一枚被无数次试印后终于满意的作品:
边缘锐利,油墨均匀,手工感与精确性并存。
它证明一件事 —— 让一个应用说另一种语言,本身 就是一枚值得钤盖的印章。

## 应用规则

- 主色:墨 #191919 / 宣纸米 #F0EEE6 / 朱砂 #D97757
- 形状:圆角方形为容器,几何笔画为内容,最小留白比例 1:1
- 字体:中文用黑体系(微软雅黑),西文用 Segoe UI Light,字距加宽
- 图案:底层暗纹不得超过 6% 不透明度;朱砂色面积占比 ≤ 15%
- 文本:只保留必要的锚定词,一切信息由形与色承载
